# Design sources

Mirror of the design work for this site, kept in step with the live design artifacts.

- `canvas/`: exported artboards from Claude Design or an equivalent tool, one file per screen.
- `design-system/`: the token sheet, brand book and component guidelines from the approved direction.
- `STATUS.md`: the handoff, covering what's decided, what's waiting on the client, and known gaps.

Check an artifact's sharing settings before its link goes to the client.
